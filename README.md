# Ondo TV : téléchargements

Fichiers d'installation officiels d'Ondo TV, le lecteur vidéo. Le plus simple est de passer par le site : https://ondo-tv.com

- Android TV, Fire TV, Android : https://ondo-tv.com/apk
- Windows : https://ondo-tv.com/windows
- Mac : https://ondo-tv.com/mac

Les fichiers sont dans les [Releases](../../releases/latest). Ondo est un lecteur : il n'héberge et ne fournit aucun contenu.
